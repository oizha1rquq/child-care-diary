# 子宫内膜厚几厘米才不影响受孕成功率？

> 更新时间：2026-09-16 (UTC+8)

子宫内膜息肉

是子宫内膜异常增生的一种疾病

那么它在一些炎症因素的刺激之下

或者在我们口服雌激素

或者孕激素的情况下

那么药物本身呢

也会对子宫内膜有一个刺激作用

它最终发生的一些异常增生

就表现为子宫内膜息肉一样的表现

那么我们在b超下呢

可以看到在子宫内膜里

有一些圆形的或者半圆形的

一些中等的回声团

那内膜息肉如果长得比较大的话

它会影响胚胎着床

同时呢内膜息肉

有时候会导致一个不规则的子宫出血

而这种子宫的出血也会影响胚胎的种植

所以呢我们在怀孕之前

如果发现有比较大的子宫内膜息肉

我们还是要给病人做一个宫腔镜的手术

把这个息肉切除

然后再让病人怀孕

否则病人一方面不容易怀孕

另外一方面还容易发生流产这些情况

而对那种比较小的内膜息肉来说

对做试管婴儿的病人来说

那么他最终花费了很多时间呀

还有金钱呀

促排卵啊取卵啊胚胎培养啊

对做试管婴儿的病人来说

胚胎都非常的宝贵

因为我们在做胚胎移植之前

如果发现内膜息肉

哪怕这个内膜息肉比较小

我们也是希望病人

在胚胎移植之前

做宫腔镜把这个内膜息肉给它处理一下

切除了内膜息肉以后再去做胚胎移植

这样呢

能保证我们体外受精胚胎移植的成功率
